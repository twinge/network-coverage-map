# Network Coverage Map

Where Cru's benefits-eligible US members live (by ZIP code, no names), checked against PHCS, EHN,
AdventHealth Provider Network and AMPS America coverage. Open the published page on GitHub Pages.

Built from the private `benefits` project with `scripts/build_coverage.py`; regenerate there and copy
`out/coverage_map.html` here as `index.html` to update.
